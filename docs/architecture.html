DedupEndNote — Architecture

Spring Boot 4.0 · Java 21

A web application that deduplicates Bibliographic Items exported from reference managers. Runs on port 9777, deployed as a fat JAR.

1. Data pipeline

How a RIS file is transformed into a deduplicated result. In Two-file mode, BibliographicItemReader runs twice — once for the Old file, once for the New file — before the combined list enters the comparison step.

All five comparison steps must pass for a pair to be considered a Duplicate. The comparison short-circuits on the first mismatch, so cheap checks (year, page/DOI) run before expensive ones (Jaro-Winkler similarity).

2. Service map

All services in edu.dedupendnote.services. Spring beans unless noted.

Pipeline orchestration

DeduplicationService

Orchestrates the full pipeline. Accepts a Consumer<String> progressReporter for WebSocket progress. Runs in a virtual thread.

BibliographicItemReader

Parses RIS files into BibliographicItem objects; coordinates Normalization during read. Hosts addNormalized* static helpers used by test fixtures.

BibliographicItemWriter

Writes deduplicated (Remove Mode) and marked (Mark Mode) RIS output; re-reads original input to preserve field order.

Enrichment (Remove Mode only)

EnrichmentService

Merges DOIs, fills missing year/pages, replaces Reply/ClinicalTrials.gov titles, normalises Cochrane page IDs. Applied to the Kept Bibliographic Item only.

Comparison — wired via FieldComparators record

DefaultAuthorsComparisonService

Jaro-Winkler author matching. Thresholds injectable via AuthorThresholds record.

DefaultTitleComparisonService

JWS title matching. Thresholds injectable via TitleThresholds record.

DefaultJournalComparisonService

Journal matching with abbreviation/initialism heuristics. Hosts static compareIssns.

DefaultPagesComparisonService

Exact-equality pages-or-DOI step. Hosts static compareSameDois.

Normalization — called from BibliographicItemReader; not Spring beans

NormalizationService

Shared utilities: normalizeToBasicLatin, normalizeHyphensAndWhitespace, DOI/ISSN/year parsing.

AuthorsNormalizationService

Last-name + initials; transposed names; group-author detection.

TitlesNormalizationService

Retractions, reprints, subtitles, HTML tags, punctuation.

JournalsNormalizationService

Abbreviations, language variants, supplement strings.

PagesNormalizationService

SP/SE/C7 fields; Roman numerals; page-range merging; e-pages.

4. Modes

Remove Mode (default)

Duplicate Bibliographic Items are removed from output. The Kept Bibliographic Item is Enriched with data from its duplicates (DOI, year, pages, title).

Mark Mode

All Bibliographic Items are written to output. Duplicates are identified by their Label — the ID of the Kept Bibliographic Item written into the RIS LB field.
